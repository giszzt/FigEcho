# 分层技术架构图 · 通用风格提示词

【图像类型】
一张扁平矢量的分层技术架构图，也可称层级堆叠式系统全景图。横向宽幅画布，推荐比例 16:9 或 21:9，纯白底，无外框。二维正视平面图示，用于白皮书内页、方案汇报、演示与印刷等使用场景，也可直接放进论文或报告。画面里只有文字容器与极少量抽象几何图元。

【内容结构】
自上而下由若干条水平层带构成，每条层带是体系中的一个层级，通常 5 至 7 层，按越贴近使用者越靠上、越贴近底层设施越靠下排列。层与层之间是自下而上的支撑依赖关系，不是时间流程，也不是分支汇聚关系。每条层带含三个槽位：最左侧通栏浅灰层名列写 <LAYER_NAME>，中部可选的分组名列写 <GROUP_NAME>，右侧主内容区是由 <ITEM_LABEL> 方块组成的规则网格。画面右侧可另设一条通高纵栏，写 <SIDEBAR_TITLE> 与 <SIDEBAR_ITEM>，用于承载与所有层平行、纵向贯通的模块，它与四层之间是包含与映射关系而非先后顺序。

【整体版式】
阅读路径为从上到下，主轴是垂直方向；每条层带内部再按从左到右扫读。画布比例 16:9。严格模块化网格，同一行方块等宽等距等高，跨层的列边界尽量对齐。层带之间留 6 至 10px 的纯白缝隙，靠底色深浅区分层次，不画分隔线。四周边距均匀，主区与右侧纵栏之间留一条明显的白通道。信息密度保持松弛，宁可留白也不压缩间距，单层信息量以不超过 3 行为宜。版式必须根据新内容的内容拓扑重新调整：每行方块数量按新内容自适应，取3至5个；分组数量与顺序按新内容拓扑重排。

【组件语言】
三类容器。标签方块为圆角矩形，圆角半径 3 至 4px 近方角，描边 1px 实线，填充为白色或极浅同色底色，左右内边距各约一个字宽，全图等高约字号的 2.6 倍。层带与分组容器为无描边的浅色填充圆角矩形，圆角 4px。数据源图元为扁圆柱体，顶部一条椭圆弧，1px 描边，浅色填充；柱体只用于真正的数据源实体，其余一律用同规格圆角矩形。三类容器的表面语言完全一致：纯平，没有阴影，没有渐变，没有发光，没有玻璃质感，没有立体厚度。若新内容本身要求嵌入外部图像素材，用同一套边框、裁切与色调规则整合进画面。

【连接线】
本风格不设连接件。画面里不出现实线、虚线、点线、折线或曲线形式的连线，也不出现任何箭头与箭头端点，因此不需要设定连线粗细与线宽，也不存在 px 或 pt 级别的连线颜色定义、直角路由、端点、分支、汇聚与交叉。层级关系全部由垂直堆叠顺序与层带底色分区表达，纵向贯通关系由通高对齐表达。新图同样不画箭头与连线。

【插图与图标风格】
默认无装饰性插图、无人物、无场景、无立体图标。允许的图元只有对内容语义有直接指代作用的几何线稿：线性风格，纯轮廓描边，1px 单色，无填充细节，正视视角，抽象度高、细节极少，整体构成一个统一的图标家族，尺寸不超过文字高度，置于文字左侧并与文字基线对齐。图标题材从新内容的实体与动作派生，保持1px单色线稿；按照新内容的对象重新设计与替换图标，不沿用任何前一张图的具体题材。

【配色】
高明度低饱和的蓝青绿冷色系。背景为白色 `#FFFFFF`；层名列底色 `#EFEFEF`；层名与分组名文字 `#1F3B63`；层带与分组容器底色浅色 `#F4F9FF`、略深 `#E8F1FD`。三个语义强调色槽位：强调色 A 描边与文字 `#22B8CC`、填充 `#F0FCFD`；强调色 B 描边 `#4C86F0`、文字 `#1F5FD8`、填充 `#EEF4FF`；强调色 C 描边与文字 `#33BE72`、填充 `#EDFBF2`。强调色必须按照新内容的语义层级重新分配颜色：强调色A给最贴近使用者的一层，强调色B给条目最多的主体层，强调色C给资源或感知类实体。同一层内不混色，全图色相不超过三种，不使用暖色作强调色。

【字体层级】
无衬线中文黑体，全部文字为粗体。层名相当于本图的主标题，字号最大，约为条目文字的 1.35 倍，字间距略微加宽，颜色 `#1F3B63`。分组名与纵栏标题相当于分区标题，约为条目文字的 1.1 倍。方块内条目文字为正文字号，与所在层强调色同色。说明文字不单独出现，语义靠容器承载。英文专有名词与缩写用无衬线斜体嵌在中文里，与中文同色同粗。长标签可降一档字号但不改字重，一律水平居中对齐，横排不旋转，行高保持一致。

【视觉气质】
技术与工程语境下的编辑感，像一份印刷精良的白皮书内页。冷静、克制、秩序感强，颜色只用来区分语义而不是制造视觉冲击。克制到没有多余的装饰，大量白色留白让画面呼吸，水平对齐与垂直节奏必须绝对整齐。

【关键风格特征】
1. 最左灰底层名列贯通，右侧独立纵向支撑栏，中间等宽方块网格，层间留白缝不画分隔线。
2. 1px均匀细描边圆角矩形，圆角3-4px，白或极浅填充，全图等高，绝对扁平。
3. 不画箭头、不画连线，关系靠堆叠顺序和底色分区表达。
4. 白底#FFFFFF，层名列#EFEFEF，层带底#F4F9FF/#E8F1FD，青#22B8CC，蓝#4C86F0描边#1F5FD8文字，绿#33BE72，无暖色。
5. 中文黑体全粗，层名放大加宽字距，英文专名用无衬线斜体。
6. 层带用浅色底块托底，同层多分组时两块底色一深一浅交替叠放。
7. 主区与右侧纵栏之间保留一条干净的白通道。

【生成约束】
文字必须完整清晰、拼写准确、无伪文字、无错字、无重影；所有标签逐字照抄给定内容，不改写不编造。关系与拓扑必须与给定内容一致，不得自行添加连线或箭头，也不得改变层级顺序。所有文字必须完整落在容器内，不裁切、不越界、不重叠、不穿过边框；画幅严格按指定比例，不拉伸不裁切。不添加与语义无关的装饰、随机配色或无语义色块。保持纯白底与无外框。某组条目不足以填满一行时左对齐留白，不拉伸方块宽度补满。
