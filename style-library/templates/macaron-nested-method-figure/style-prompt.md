【图像类型】

横向多面板技术方法图，用于学术论文或技术报告的总览插图（pipeline / framework overview figure）。画布为宽幅横图，比例约 2:1（可在 16:9 到 2.2:1 之间按内容量调整）。要求 300dpi 级别的清晰度，所有文字必须可读、不糊、不裁切，整图在缩小到半栏宽时仍能辨认出分区结构。

【内容结构】

按新内容的真实拓扑组织 2–4 个大写字母编号的主模块，横向铺开，命名格式为「a. 模块名 / b. 模块名 / c. 模块名 / d. 模块名」。当某一列内容较轻时，允许一列纵向切成上下两个主模块（形成 2+1+1 或 2+2 的错位栅格），不要为了对称硬凑等宽四栏。

1. [主模块一]：[并列要素的枚举或覆盖范围，用小卡片网格铺陈]
2. [主模块二]：[顺序性处理流程，用箭头串联的步骤链]
3. [主模块三]：[核心方法的输入—处理—输出结构，中心放置处理主体，左右各接输入项与约束项，下方接输出结果]
4. [主模块四]：[带序号的多阶段质控或校验流程，①②③ 自上而下堆叠]

文字负载预算：每个主模块标题 ≤ 8 个汉字或 3 个英文词；每个主模块内不超过 4 个内层卡片；每个内层卡片内不超过 4 个白色小方块或 3 条短条目；单个标签 ≤ 6 个汉字或 2 个英文词；只有「输出示例」类卡片允许出现 2–4 行完整句子的说明文字，其余层级一律短标签。绝不在小方块里塞长句。

【整体版式】

白色底，四周留 2%–3% 画布宽的安全边距。宏观上用等高的纵向列切分主模块，列与列之间留出明显的白色沟槽（约为列宽的 4%–6%）。每一列内部是自上而下的紧凑网格，卡片之间保持一致的小间距，形成「外松内紧」的节奏——模块之间大留白，模块内部信息密度高。

阅读路径自左向右、每列内自上而下。视觉重心落在中间列的核心处理模块上：它占据最大的连续面积，内部有一个居中的处理主体图标，四周留白比其他卡片更充裕。

嵌套层级固定为四级：标题条 → 虚线宏观框 → 彩色内卡 → 白色微卡。不得超过四级，也不得把四级压成同一种卡片。分区数量、每区卡片数、箭头走向全部按新内容的关系重算，不照搬固定栏数。

【组件语言】

标题条：每个主模块顶部一条独立的浅灰色圆角横条（圆角约为条高的 25%），横条与下方内容之间有明显缝隙，不共用边框。标题居中，粗体黑色。

虚线宏观框：标题条下方是一个大圆角矩形，1px 灰色虚线描边（虚线段短、间隔均匀），内部透明，用于把该模块的所有内容整体圈住。

彩色内卡：宏观框内是若干圆角矩形卡片（圆角约 12–16px），淡彩填充 + 同色系加深 1–1.5px 实线描边。内边距充足，卡片内文字与边框之间至少留一个字高。

白色微卡：彩色内卡里嵌套白色小方块，1px 浅灰描边，圆角更小（6–8px），每个微卡是「图标 + 一行短标签」的固定搭配，标签在图标上方或下方，居中对齐。

条目列表：需要枚举属性时，用彩色内卡 + 短横线「-」引导的 2–3 条词组，绝不用圆点项目符号或长句。

序号徽章：多阶段流程用实心黄色圆形徽章加黑色数字（①②③），置于该阶段卡片的左上角，压在卡片边线上。

勾选标记：校验类结论用实心圆形勾号（绿色或橙色）贴在被校验项右侧或左侧，被校验项的文字加下划线。

【连接线】

唯一的连接语言是细黑色实线箭头：1.5–2px 线宽，纯黑，端点为实心三角箭头。走向以水平或垂直直线为主，需要拐弯时用一次 90 度折角，绝不使用曲线、贝塞尔或双箭头。

分支从一个共同起点扇出为多条并列箭头；汇聚时多条箭头指向同一个方框的同一条边。箭头始终起于卡片边缘、止于目标卡片边缘，不穿过卡片内部，不与其他箭头交叉。

跨模块的转折关系不用箭头，而用一个大面积的淡彩实心三角形（浅桃色或浅紫色）压在两个模块的接缝处，尖端指向下游模块，作为无文字的方向暗示。

虚线只用于分组包裹，不用于表示关系。

【插图与图标风格】

统一的扁平矢量插画语言，无描边或极细描边，每个图标 3–5 个纯色块，无渐变、无阴影、无 3D。视角一律正面或轻微 3/4，细节等级中等偏低——可辨认对象类别即可，不刻画纹理。

人物一律画成半身或胸像的清爽卡通形象，圆润五官、简化发型、纯色衣着，不写实、不描摹真人，不同人物之间保持同一套画法与头身比。

图标与文字的面积比约为 1:1，图标位于白色微卡的中央或上半部，文字紧贴其下。所有图标视觉重量一致，不允许某一个明显更精致或更粗糙。

根据新内容自身的实体、对象和动作选择图标题材（有什么概念就画什么概念的具象化对象），不预设任何固定题材清单。当某个概念没有合适的具象对象时，改用几何示意：小型条形图、坐标轴、时间轴刻度、网格方阵、彩色方块序列，仍保持同一套扁平纯色画法。

【配色】

背景 #FFFFFF，占据全图约 35% 的可见面积（含所有沟槽与内边距）。

结构色：标题条填充 #EFEFEF，虚线宏观框描边 #B5B5B5，白色微卡描边 #D9D9D9。

文字色：主标题与模块标题 #141414，微卡短标签 #2A2A2A，说明性正文 #4A4A4A。

连接线：箭头与折线一律 #111111。

强调色采用中性槽位，根据新内容层级与模块分组重新映射颜色，一个模块内保持单一色相：

- 强调色 A（冷蓝系）：填充 #DCE9F7，描边 #9FC2E6，同色系文字 #2B5FA8
- 强调色 B（暖黄系）：填充 #FDF2DC，描边 #E7C579，同色系文字 #A9761B
- 强调色 C（草绿系）：填充 #E5F3E7，描边 #A6D2AD，同色系文字 #2E7D46
- 强调色 D（淡紫系）：填充 #EDE6F8，描边 #B7A4DC，同色系文字 #6A46B0
- 强调色 E（浅粉系）：填充 #FBE4EC，描边 #EFA8C3，同色系文字 #B03A6B

功能色固定：序号徽章 #F5C518，通过标记 #2FB344，次级标记 #F08C2E。

所有淡彩填充的明度都在 90%–96% 区间、饱和度低于 25%，只负责分区不抢注意力；饱和度高的颜色只出现在图标内部、序号徽章和勾号上，总面积不超过全图 8%。同一个主模块内的所有卡片使用同一族强调色的深浅变化，跨模块才换色相。

【字体层级】

全部使用几何或中性无衬线字体（Helvetica / Arial / Source Han Sans / Noto Sans 一类），不使用衬线体、手写体或装饰体。

- 主模块标题：最大字号，Bold，黑色，居中，字号设为基准值 1.0
- 模块内彩色内卡的分区标题：0.65–0.7 倍，Bold，取该卡所属强调色的同色系文字色，居中
- 白色微卡短标签：0.45–0.5 倍，Regular 或 Medium，深灰，居中
- 条目列表：0.5 倍，Regular，左对齐，行高 1.4
- 输出示例类长文本：0.45 倍，Regular，左对齐，行高 1.5，关键片段可用强调色文字或尖括号标记区分
- 需要强调的结论性词组加下划线，不加粗、不变色

字号层级之间保持清晰跳档，相邻两级差值不小于 25%。

【视觉气质】

学术论文插图的严谨骨架，配上教科书或科普手册的亲和外观。信息组织是工程化的——严格的网格、清晰的嵌套、单一的箭头语言；表面处理却是柔和的——大面积白底、低饱和淡彩、圆润卡片、可爱但不幼稚的扁平人物插画。整体给人「一眼能看懂全流程，凑近还能读到细节」的感觉，克制、明亮、有秩序感。

要避免滑向三类常见模板：不要变成深色背景加霓虹发光线的「科技感」海报；不要变成靠大色块和图标堆砌的商业信息图；不要变成每个方框都长一样、只靠箭头串起来的流程图线框稿。区别来自四级容器嵌套、淡彩分区编码、纯黑细箭头与扁平卡通插画这四者的同时出现，缺一项就会塌回普通模板。

【关键风格特征】

1. 四级容器嵌套：独立浅灰圆角标题条 → 灰色虚线圆角宏观框 → 淡彩实心内卡 → 白色小微卡，四级各有不同的描边与填充语言，层级差必须肉眼可辨。
2. 淡彩分区编码：同一主模块内统一色相，跨模块才换色，填充明度 90%+、饱和度 <25%，描边取同色系加深值，颜色只做分组不做装饰。
3. 单一箭头语言：全图只有纯黑细实线加实心三角箭头一种关系符号，直角走线、边缘起止、互不交叉；虚线仅用于包裹分组，跨模块转折改用大面积淡彩实心三角。
4. 扁平纯色插画与几何示意同场：3–5 色块的无阴影扁平图标、圆润简化的卡通人物胸像、以及条形图坐标轴一类的几何示意，三者共用同一套画法与视觉重量，统一嵌在白色微卡里。
5. 外松内紧的密度节奏：模块之间留出明显白色沟槽，模块内部卡片紧密排列，形成呼吸与密度的交替，白底可见面积始终维持在三分之一以上。
6. 粗黑标题 + 彩色副标题的双层文字编码：主模块标题一律粗体纯黑居中，内卡分区标题用所属强调色的同色系深色，微卡标签退回深灰，靠色彩而非字号承担一部分层级。
7. 小型功能标记系统：黄色实心序号圆徽压在阶段卡左上角，绿色/橙色实心勾号贴住被校验项，被校验项文字加下划线——这一套微符号让流程图带上审校清单的气质。

【生成约束】

硬约束：

- 所有文字必须拼写正确、完整、清晰可读，不出现乱码、重复字符或半截单词
- 模块之间的关系拓扑必须与给定内容一致，箭头方向不得反转
- 不编造未给定的模块、步骤、数值或标签
- 任何卡片、图标、文字都不得被画布边缘裁切，不得相互遮挡
- 不出现无语义的装饰性纹理、光效或几何碎片

风格默认：

- 默认纯白背景与全平面处理，渐变、发光、玻璃拟态、投影和 3D 材质默认都不出现，画面深度只靠描边、叠层与颜色对比表达
- 默认无衬线字体、圆角矩形容器、纯黑直角箭头
- 默认低饱和淡彩分区，高饱和颜色仅限图标内部与功能微标记

条件规则：

- 当内容本身需要或使用者提供了 Logo、照片、外部插图、真实截图时，允许作为素材插入，但必须统一套用本风格的圆角白色微卡边框、同一尺度和同一层级位置，色调向低饱和方向压一档
- 是否出现人物插画取决于内容是否涉及角色、使用者或人的行为；不涉及时全部改用对象图标或几何示意，不硬塞人物
- 主模块数量、每列的上下切分方式、箭头的分支与汇聚形态，全部按当次内容的关系重算
