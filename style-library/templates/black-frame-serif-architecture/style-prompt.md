【图像类型】
生成一张横向宽幅的学术技术架构图、技术路线图或研究框架图。画面采用白底二维信息图语言，强调工程结构、机制关系和快速扫读；适合论文插图、研究汇报与屏幕展示，输出清晰锐利的高分辨率图片。

【内容结构】
1. <PRIMARY_MODULES>：填写新内容中的主模块、阶段或层级。
2. <SECONDARY_GROUPS>：填写隶属主模块的子机制、对象或结果。
3. <RELATIONSHIPS>：填写顺序、依赖、分支、汇聚、反馈或包含关系。
4. <SUPPORTING_ASSETS>：仅在用户提供或内容必需时填写需要插入的标识、照片或外部插图。
主模块和子模块的数量由新内容决定；优先形成一个清楚的主叙事和必要的次级关系，不把无关信息机械排成同款卡片。

【整体版式】
采用 16:9 左右的横向画布。根据新内容拓扑重算主区数量、相对宽度、上下层级和阅读路径；当内容存在一个占主导的核心过程时，可用较宽主区配合较窄的输入、背景或约束区，当内容关系不同则调整为相应的分层、分支或多面板结构。保留非对称宽度节奏、粗黑宏观边界、严格对齐和局部上下分层的视觉语言，不固定某一业务位置。主阅读方向保持单一明确，局部允许自上而下展开。采用紧凑工程网格，每个主区放 2–5 个短标签，重复卡片等高等宽；边缘保留均匀安全距，通过层级、分组和留白压缩信息密度，不依赖不可读的小字号。

【组件语言】
每个宏观区顶部设置浅灰标题带，白色主面板内嵌彩色机制框和暖色虚线子框，形成三级容器。外层宏观分区使用约 2.5–3.5 像素的直角粗黑框；机制节点使用 10–16 像素小圆角彩色框；次级标签可使用梯形、折角便签或描边对象框，但同类组件必须保持一致。白色作为主要容器底色，不用表面效果替代层级。内边距约为模块高度的 8%–12%，同类卡片严格等高对齐。

【连接线】
主流程使用线宽约 3 像素的 #151515 粗黑实线和白心三角箭头；反馈、映射或跨区关联使用线宽约 2.5 像素的 #A64573 或同组暖色虚线曲线。只为真实关系绘制箭头，主线与反馈线使用不同颜色和线型。分支从明确节点展开，合并关系在进入目标前先汇流，包含关系优先用外框表达。连线沿容器边缘和留白通道路由，端点与卡片边缘保持呼吸距离，避免交叉、回折混乱和穿过文字。

【插图与图标风格】
图标采用正视角扁平线稿，深色轮廓约 2 像素，内部只使用一至两种功能色；保持统一视角、轮廓、抽象度和中低细节复杂度。根据新内容中的实体、对象与动作选择图标或插图题材，不沿用任何既有主题的对象清单。图标与短标签绑定，只帮助识别对象，精确技术含义由文字和连接关系表达。不需要具象图标时，使用同一描边语言的几何符号。用户提供或内容必需的标识、照片与外部插图可作为辅助素材插入，并用统一边框、裁切、色调和尺度纳入组件系统。

【配色】
背景使用 #FFFFFF，宏观标题带使用 #F1F1F1，主体文字和结构线使用 #151515。功能色保留三组中性强调槽位：强调色 A 使用酒红 #A64573、深描边 #67364F；强调色 B 使用橙色 #FF8B38、黄色 #F8B52B；强调色 C 使用青色 #09C9D1、深蓝 #0B4AA2。根据新内容层级、分组与关系重新分配强调色 A、B、C 的具体语义；同一层级内保持一致映射，不把任何色组永久绑定到某类业务对象。白色与浅灰约占 72%–80%，功能色约占 20%–28%；以黑白灰构建版式骨架，彩色只承担分组、层级和关系提示，避免随机互换和无依据的彩虹配色。

【字体层级】
分区标题使用大号高字重衬线中文字体，节点标题使用粗体无衬线中文字体，短注释使用中等字重无衬线。总标题最大，分区标题次之，节点标题保持高字重，正文和说明使用正常行高并左对齐；标题字号约为正文的 1.8–2.2 倍，短注释不超过两行。中文可使用思源宋体或宋体作为标题替代，思源黑体或黑体作为正文替代。数字、英文缩写和公式保持清晰，必要时使用斜体衬线形成学术反差。

【视觉气质】
形成论文方法图与工程架构图结合的视觉气质：白底、粗框、浅灰标题带、明确箭头和少量高饱和功能色，信息密度较高但具有严谨编辑秩序。默认采用纯平面印刷质感，层级主要来自描边、容器嵌套和色块对比；当本次需求明确需要其他媒介或用户提供辅助素材时，仍以这一结构语法统一视觉。避免滑向缺少层级的通用商务卡片堆叠和无语义营销装饰。

【关键风格特征】
1. 粗黑宏观外框、非对称宽度节奏与局部上下分层共同组织横向系统，但分区数量和比例按新内容拓扑重算。
2. 浅灰标题带、白色主面板、彩色圆角机制框和暖色虚线子框组成三级容器。
3. 粗黑实线空心箭头承担主流程，酒红或暖色虚线承担反馈、映射和跨区关联。
4. 黑白灰建立结构骨架，酒红、橙黄、青蓝作为中性强调色槽位，按新内容层级重新映射语义。
5. 大号粗衬线分区标题与粗体无衬线节点文字形成学术型层级反差。
6. 统一正视角扁平线稿图标与短标签绑定，具体题材由新内容动态派生。
7. 严格网格、重复卡片尺度、短标签与均匀安全距共同支撑高信息密度。

【生成约束】
硬约束：所有文字清晰、完整、拼写正确；关系、拓扑和箭头方向准确；不编造未提供的数据、阶段、机构、指标与结论；不带入其他主题的专有文字、对象或业务映射；画面不得裁切、越界、重叠，连线不得穿过文字。
风格默认：优先采用平面印刷质感、清楚描边和克制装饰；避免把所有层级压成同款卡片。
条件规则：Logo、照片、外部插图或特殊表面效果仅在用户提供、内容必需或任务明确要求时使用，并与本风格的容器、色调、尺度和信息层级协调。
