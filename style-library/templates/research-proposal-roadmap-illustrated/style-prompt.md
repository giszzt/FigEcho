【图像类型】

纵向科研技术路线图、机制示意图，用于申报书、论文与技术报告。高清输出，最小说明文字仍清晰。画幅与阶段数量根据实际内容选择，标题与页脚按任务决定。

【内容结构】

<TITLE>为可选总标题。<STAGES>替换为真实阶段及必要关系。每个阶段含<INPUT>、<MECHANISM>、<OUTPUT>中的适用部分，依据关系选择分解、转换、前后对照或空间机制图。通常3–7个阶段，每带3–6个主要短标签，标签4–14字、说明不超过两行。图示承担变化与关系，文字保留方法名与输出。

【整体版式】

各分区按网格对齐。

按新内容拓扑重算阶段数、内部分栏与画幅，不固定四行或无标题。建议竖向 3:4 或 2:3，按内容密度选择并锁定。阅读路径从上到下，行带内部从左到右或分支汇聚。纵向行带由左侧窄标签和右侧宽内容区构成，行带高度随过程复杂度变化。左标签占宽5%–9%，外边距2%–4%，行带间留一条清晰通道。机制示意占内容区40%–65%；视觉重心给最关键转换。

【组件语言】

容器使用圆角矩形与标题条，细实线描边。

浅灰虚线外框包住细实线子面板，子面板顶部贴浅彩标题条，分组不超过三层。外框圆角约8–12px，细虚线约1px；内框同色实线1px，小圆角。白底或极浅填充，文字内边距约一字高，标题条高度一致。图像与标签合为节点，避免重复层层套框。同级面板对齐，标题条贴上沿，子面板最多三层嵌套。

【连接线】

模块间用近黑短实线箭头，图内映射和路径用有语义图例的彩色虚线。流程线颜色 #1A1A1A、约1–1.5px，小实心三角端点，优先水平与直角路由，分支汇聚避开文字；双向对应只有语义确需时使用。阶段流程与图内机制分别编码，必要关系才连线。行带间必要的依赖用短竖箭头。

【插图与图标风格】

机制插图占子面板主体，紧邻短标签，同一对象以输入、中间态和输出连续呈现。按新内容实体选择插图，表现其转换、分解、对照或空间关系。统一细轮廓线稿加低饱和面性填色，空间关系用轴测或俯视，结构用正视或剖面；同一比较组视角和尺度一致。保留解释机制所需的中等细节，不添无关纹理。人物使用中性简化符号，题材随内容变化。真实素材与生成示意区分，不把示意冒充实验结果。

【配色】

白底为主，每条行带使用浅彩填充与同色深描边，插图保留克制的自然色。画布 #FFFFFF，结构虚线 #C9CDD4，分组底板 #F2F2F2，正文和流程箭头 #1A1A1A，次级文字 #333333。强调A蓝填充 #C5D9F1 / 描边 #4A78B8；B紫 #E6D8F0 / #9070AE；C琥珀 #FDE9C4 / #DFA33C；D绿 #CFE3B8 / #6E9E4E。根据新内容层级分配强调色，颜色不绑定固定学科。白灰占约55%以上，深色主要用于文字轮廓；图内自然色不决定行带分类。

【字体层级】

中文无衬线分级排字，竖向标签加粗，子面板标题居中，图下注释紧邻对象。主标题如需出现为正文1.8倍，模块标题1.15–1.3倍加粗，阶段标签1.3–1.5倍，正文基准字号，说明文字0.85–0.95倍；同层级字号一致，图下注释与对象相邻。行高1.25–1.4，不用手写体与过度字距。

【视觉气质】

科研报告的清楚、严谨与机制可解释性。用图示帮助读者看到对象如何变化，保持行带秩序与面板对齐；避免营销海报的发光、浮动卡片和无语义装饰，也避免所有内容退化为相同文字方框。

【关键风格特征】

1. 纵向行带由左侧窄标签和右侧宽内容区构成，行带高度随过程复杂度变化。
2. 浅灰虚线外框包住细实线子面板，子面板顶部贴浅彩标题条，分组不超过三层。
3. 机制插图占子面板主体，紧邻短标签，同一对象以输入、中间态和输出连续呈现。
4. 模块间用近黑短实线箭头，图内映射和路径用有语义图例的彩色虚线。
5. 白底为主，每条行带使用浅彩填充与同色深描边，插图保留克制的自然色。
6. 中文无衬线分级排字，竖向标签加粗，子面板标题居中，图下注释紧邻对象。
7. 界面容器采用平面细描边，插图可用轻材质和轴测体积而不添加界面投影。

【生成约束】

硬约束：文字准确清晰，关系拓扑忠于内容，不编造数字、数据或结论；无文字裁切、重叠、箭头穿字及源内容泄漏；不加无语义装饰。风格默认：白底浅彩行带与细边框，界面无投影；容器保持平面，插图的材质与体积依内容需要采用。条件规则：用户提供照片、地图、Logo或外部证据可嵌入，统一尺度和容器，并标明素材性质；标题与页脚按任务开启，节点数量按内容调整。每区三至六个主要标签，复杂关系优先用图示解释而非缩小字号。
