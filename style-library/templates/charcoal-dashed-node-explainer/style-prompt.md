# 深炭黑霓虹节点技术图 · 通用风格提示词

## 【图像类型】
一张信息图式技术科普长图，非照片、非3D渲染、非UI截图。矢量风格平面图，文字锐利可读，无手写体、无透视变形、无景深模糊。默认比例 5:6，可按内容改为 4:5、3:4 或 1:1，选定后全图统一，不拉伸不裁切。

## 【内容结构】
自上而下三段式：顶部标题条（左标题、右品牌位占位符 {BRAND}，无品牌则留空）；主区 {SECTION_1} 承载中心主体向 4–7 个分支的辐射机制；次区 {SECTION_2}/{SECTION_3} 并排两个面板，分别承载分类树与清单对照。面板数量、栏数与阅读路径按新内容的真实拓扑调整，只保留分区比例、留白节奏与对齐语法，不硬塞固定格子。

## 【整体版式】
深色底 + 圆角矩形面板分区，圆角 18–24px，面板间外边距约画布宽 3%，内部留白充足。面板标题骑在顶边线上，顶边在标题左右断开形成缺口。主区中心辐射，次区可为辐射或分隔线分行的条目列表。密集图标区与空白区交替，不追求填满。面板数量、宽度比与阅读路径按新内容的内容拓扑重新调整，模板只固定分区比例、留白节奏与对齐语法。

## 【组件语言】
节点框：圆角矩形（半径约 10px），2px 描边，内部透明，文字与描边同色。中心主体：正圆，实心深色填充 + 2px 亮色描边。胶囊标签：全圆角实心色块 + 白色粗体字，每图不超过 6 个。成组容器：比主面板略亮一档的次级圆角面板，其胶囊标签骑在子面板顶边上。一律无投影、无渐变、无玻璃拟态。

## 【连接线】
白色虚线箭头，线宽 2px，短划与间隙约 8:6，末端实心细三角箭头。单向单箭头、双向两条平行反向虚线、弱关联更细更疏的点线。放射状排布，允许弧线绕行，不穿过任何文字或图标。中段可加浅灰小字关系标签 {RELATION_LABEL}，字号为正文 0.8 倍。

## 【插图与图标风格】
彩色扁平贴纸风图标：粗描边、块面填色、轻微高光，64–96px，直接落深色底，下方居中配短标签。按新内容的实体、对象与动作重新设计图标题材，模板只保留贴纸画法本身，不预设任何固定题材。同图内绘制手法与描边粗细统一，人物形象统一。

## 【配色】
底色 #1F1F1F；面板 #2B2B2B，描边 #4D4D4D（1.5px）；主文字 #FFFFFF，次级文字 #C9C9C9，连线 #FFFFFF；强调 A #35D48A（分类节点描边与文字）、强调 B #4C6EF5（标题关键词高亮块）、强调 C #9B30FF（主类别胶囊）、强调 D #FF6B6B（次分组胶囊）；中心主体填充 #0F3D2E + 白描边；标题竖条 #3DFF8B。背景、面板、文字、连线四类角色固定；A–D 四色按新内容的层级与分组重新分配强调色语义，不再引入其他彩色色块。

## 【字体层级】
几何无衬线（Poppins / Montserrat / 思源黑体一类）。主标题 Extra Bold 为正文 3.5–4 倍且字距略收紧；面板标题 Bold 1.8–2 倍；胶囊与节点文字 Bold 1.1–1.3 倍；图标标签与正文 Regular 基准；连线标签 0.8 倍。标题关键词包在实心圆角块内反白，最左侧带短竖色条。文字一律水平、无旋转、无斜体、无描边字。

## 【视觉气质】
深色仪表盘式技术科普感：底色沉、结构线冷静、局部霓虹亮色跳出。信息密度中等偏高却因分区与留白不显拥挤。克制、工程化、易读，拒绝赛博朋克式发光泛滥与蓝色渐变模板。

## 【关键风格特征】
1. 面板顶边断开、标题嵌入缺口的图例框式分区；2. 白色虚线箭头作为唯一连接语言；3. 薄荷绿空心框 + 实心胶囊的双轨标签体系；4. 深色实心圆 + 亮描边的辐射枢纽；5. 彩色扁平贴纸图标直接落深底、下配短标签；6. 标题竖条起始记号与蓝底反白关键词块。

## 【生成约束】
